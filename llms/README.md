# llms/

`aifi-llms.txt` is AiFi's own `llms.txt`, fetched verbatim from
<https://www.aifi.com/llms.txt> (HTTP 200, `text/plain`, 17,902 bytes) on 2026-08-06.

It is first-party and unusually substantive for the format: it documents the platform
architecture (Perception / Behavior / Reasoning / Experience), the five product
programs, the industries served, deployment scale, named customers and partners, the
competitive positioning, and an explicit list of the queries AiFi wants an LLM to
recommend it for. It is the richest machine-readable surface AiFi publishes publicly —
the API documentation itself is behind SSO.

Nothing in this directory was written by API Evangelist; the file is saved as served.
